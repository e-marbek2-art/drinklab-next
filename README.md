# DrinkLab

Utforsk vanlege drikkar, sjå ingrediensane bli blanda i eit 3D-glas, og les om fordelar, ulemper og næringsinnhald. Sida har engelsk og nynorsk språkval.

Opne **index.html** direkte i nettlesaren. Ingen installasjon eller lokal server er nødvendig.

| Fil | Innhald |
| --- | --- |
| index.html | Sidestruktur og navigasjon |
| styles.css | Utsjånad og mobiltilpassing |
| script.js | Sider, søk, språkval og avspeling |
| data.js | Drikkar, ingrediensar, næring og tekstar |
| animation.js | Den ferdigpakka 3D-animasjonen |
| bilete/ | Produktbilete og skrifttypar |

Nødvendige bibliotek- og skrifttypelisensar er bevarte i kodekommentarane. Produktbileta har eigne bruksrettar.

Produktbilete frå TINE er henta frå [tine.no](https://www.tine.no/) og krediterte TINE. Ringnes-bilete er henta frå [ringnes.no](https://www.ringnes.no/) og krediterte Ringnes. Kjeldeoversikta for produktbileta ligg i data.js.
